# Orbit Metrics

Workspace dimostrativo offline per le schermate di VincodeLab.

Il progetto simula una piccola dashboard tecnica con:

- metriche di affidabilita tipizzate;
- un tema Graphite condiviso;
- test unitari essenziali;
- un database SQLite locale con dati innocui.

## Comandi

```sh
npm ci
npm run check
```

Tutti i contenuti sono fittizi e possono essere rigenerati con lo script del repository.
